# ♟️ Agentic AI Persona Agent: Grandmaster Chess Coach & Study Buddy

This repository contains an implementation of an autonomous persona agent built for an **Introduction to Agentic AI** course. It adapts a foundational quiz-bot architecture (**Study Buddy**) into a domain-specific expert agent (**Grandmaster Viktor**) capable of analyzing chess games, evaluating tactical blunders, and autonomously logging insights to a local review file using tool-calling capabilities.

---

## 🚀 Key Features

* **PDF Knowledge Integration:** Dynamically extracts reference notes (chess opening principles, tactical motifs, and rules) from a local PDF file (`notes/notes.pdf`) to ground the agent's reasoning.
* **Custom Persona System Prompt:** Combines a strict, no-nonsense persona with context notes and precise behavioral rules to maintain character during execution.
* **Autonomous Tool Calling:** Implements a custom Python tool (`save_chess_analysis`) that logs game analyses, game labels, and direct **Lichess** links to an external text file (`chess_review_log.txt`).
* **Multi-Turn Agent Loop:** Features an advanced `while` loop capable of handling multiple sequential or simultaneous tool calls before generating a final response.
* **Interactive UI:** Powered by **Gradio** for a clean, browser-based chat interface.
* **Enterprise Integration:** Connects to Azure OpenAI via API Management (APIM) using the `gpt-5.4-ptu` deployment.

## ⚙️️ Setup and Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/agentic-ai-chess-persona.git
cd agentic-ai-chess-persona

```

### 2. Set Up a Virtual Environment (using `uv` or standard venv)

```bash
uv venv
.venv\Scripts\activate   # On Windows
# source .venv/bin/activate  # On macOS/Linux

```

### 3. Install Dependencies

```bash
uv pip install --upgrade openai pypdf gradio python-dotenv starlette

```

### 4. Configure Environment Variables

Create a `.env` file in the root directory of the project and add your enterprise Azure OpenAI credentials:

```env
AZURE_OPENAI_ENDPOINT=https://your-resource-name.openai.azure.com/
AZURE_OPENAI_API_KEY=your-apim-key-here

```

## 💻 How to Run

1. Open your Jupyter Notebook environment or IDE (such as Cursor or VS Code).
2. Ensure your chess reference notes are saved as a PDF at `notes/notes.pdf`.
3. Run the cells sequentially to:
* Authenticate with Azure OpenAI.
* Extract the PDF notes and initialize the Grandmaster persona.
* Register the `save_chess_analysis` tool and its JSON schema.
* Initialize the agent loop (`chat` function).


4. Launch the Gradio web interface by running the final cell:
```python
gr.ChatInterface(chat).launch(inbrowser=True)

```

## 🕹️ Example Usage

Once the Gradio interface opens in your browser, you can paste a game PGN or a game summary directly into the chat:

> *"Viktor, please review this rapid game: [Event 'rated rapid game'] [Site '[https://lichess.org/lI1yY8TT](https://lichess.org/lI1yY8TT)'] 1. e4 e5 2. Nf3 Nc6 3. Bc4 f6..."*

The agent will analyze the moves against the core reference notes, identify inaccuracies or blunders, and **autonomously invoke your custom tool** to record a structured entry into `chess_review_log.txt` complete with a clickable Lichess link and clean formatting!
